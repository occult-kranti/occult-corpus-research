# ACM artifact review findings

Source: ACM, Artifact Review and Badging — Current, https://www.acm.org/publications/policies/artifact-review-and-badging-current

Key definitions:

- Repeatability: the same team obtains the measurement again using the same setup and procedure.
- Reproducibility: a different team obtains the same result using the author’s artifacts and the same experimental setup.
- Replicability: a different team obtains the result using a different setup and independently developed artifacts.

ACM’s artifact framework separates badges for artifacts evaluated, artifacts available, and results validated. Functional artifacts should be documented, consistent with the paper, complete as far as possible, exercisable, and supported by verification/validation evidence. Reusable artifacts exceed minimal functionality through careful documentation and structure.

Application to WizardForums corpus research: distinguish (a) rerunning the same smoke tests on the same frozen fixture, (b) rerunning the analysis from a released schema and code against an access-controlled or synthetic fixture, and (c) independent replication using a separately collected corpus. Do not claim public data reproducibility when forum content is dynamic, access-controlled, or legally/ethically restricted.
