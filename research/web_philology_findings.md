# Web philology findings

Source: Christopher Plaisance, “Methods of Web Philology: Computer Metadata and Web Archiving in the Primary Source Documents of Contemporary Esotericism,” International Journal for the Study of New Religions 7(1), 2016, pp. 43–68, https://doi.org/10.1558/ijsnr.v7i1.26074

The article argues that critical analysis of first-generation electronic objects in contemporary esotericism requires adapting textual scholarship to digital forensics, computer metadata, and web archives. It calls this approach “web philology” and treats digital witnesses as historically situated objects rather than transparent containers of authorial meaning.

Application to WizardForums: preserve crawl timestamps, canonical and source URLs, page boundaries, thread/post IDs, edits/deletions, quote-source edges, attachment/link metadata, and archive manifests. Treat each post as a dated digital witness, distinguish author claims from later interpretation, and avoid collapsing multiple versions of a ritual/book description into one timeless text. Link and resource analysis should track provenance and change over time.
